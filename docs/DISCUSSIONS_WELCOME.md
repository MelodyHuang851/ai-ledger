## About This Project

One-Sentence Accounting is a privacy-focused, AI-powered bookkeeping tool that helps you track your expenses with natural language. The core philosophy is simple: **记账的意义不是记录过去，而是改变下一笔** (The purpose of accounting isn't to record the past, but to change the next transaction).

Key features:
- 📝 One-sentence bookkeeping with natural language
- 💰 Real-time budget impact calculations
- ⚠️ Early overspending alerts
- 📊 Natural language review and querying
- 🛡️ All data stays local on your device
- 🚀 Zero dependencies, runs anywhere Node 22+ is available
