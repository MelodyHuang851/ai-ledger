# Privacy Policy

## Data Collection and Usage

One-Sentence Accounting is designed with privacy as a core principle. Here's how we handle your data:

### Local Data Storage
- All your financial data is stored locally on your device in JSON format
- No data is sent to external servers for storage
- You have full control over your data and can delete it at any time

### Data Processing
- **Accounting Data**: All calculations (budget impacts, spending predictions, aggregations) are performed locally on your device
- **AI Integration**: When you ask questions, only aggregated, anonymized data is sent to the LLM for natural language processing
- **No Personal Identification**: We never collect or store personally identifiable information

### API Key Usage
- Your Zhipu API key is stored locally in `secret.json` (encrypted if possible in your environment)
- The key is only used to communicate with the LLM service for parsing natural language
- The key is never transmitted to external servers

## Data Security

- All data remains on your local machine
- No internet connection is required for basic accounting functionality
- Sensitive financial information never leaves your device

## Third-Party Services

- We use Zhipu AI's language model for natural language processing
- Only aggregated, non-identifiable data is sent to the LLM service
- No personal data is shared with third parties

## Your Rights

- You have the right to access and delete your data at any time
- You can export your data in JSON format
- You can modify or delete your API key configuration
